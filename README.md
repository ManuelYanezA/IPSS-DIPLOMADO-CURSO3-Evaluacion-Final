## 🚀 Cómo levantar el proyecto

Debe ir a este repositorio, hacer click en "Code" y copiar la ruta que le aparece.
Luego debe ir a la consola de Git, en la ubicación que desee, y utilizar los siguientes comandos:

```bash
git clone https://github.com/ManuelYanezA/IPSS-DIPLOMADO-CURSO3-Evaluacion-Final.git
cd IPSS-DIPLOMADO-CURSO3-Evaluacion-Final
npm install
npm run dev
```

Con "npm install" se asegura de instalar todas las dependencias del proyecto.

**Configurar MongoDB:** debe abrir `config/db.js` y reemplazar `<usuario-mongo>`, `<clave-secreta>`, `<hostname>` y `<nombre-base-de-datos>` por las credenciales de su propio cluster ANTES de utilizar `npm run dev`, caso contrario, el servidor no le responderá.

Una vez teniendo todo correctamente configurado, la consola le dará un mensaje de confirmación de que el servidor está escuchando en el puerto que usted defina en `server.js` (por defecto, el puerto 3000).
